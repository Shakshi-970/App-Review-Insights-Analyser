# Weekly Product Review Pulse — AI Agent

An autonomous AI Agent that scrapes, clusters, and summarizes app-store reviews weekly, then delivers insights to a Google Doc and a Gmail teaser — all coordinated by an LLM reasoning loop built on Groq + MCP.

## How to Re-Run for a New Week

### Prerequisites

```bash
pip install -r requirements.txt
cp .env.example .env   # fill in GROQ_API_KEY, GMAIL_APP_PASSWORD, etc.
```

Start the local Gmail MCP server (required — HuggingFace blocks outbound SMTP):

```bash
python src/phase6_gmail_mcp/server.py --transport sse --port 8001
```

### Run for the current week

```bash
PYTHONPATH=. python -m src.phase7_orchestration.agent --product Groww
```

### Run for a specific week

```bash
PYTHONPATH=. python -m src.phase7_orchestration.agent --product Groww --week 2026-W17
```

### Backfill all missing weeks

```bash
PYTHONPATH=. python -m src.phase7_orchestration.agent --product Groww --backfill
```

The agent is **idempotent** — re-running the same product + week is a no-op if a successful run record already exists in `run_log.db`.

## Theme Legend

Each weekly report groups reviews into **themes** discovered automatically by the pipeline. Here is what each component means:

| Component | Description |
|---|---|
| **Theme name** | A short label generated by the LLM summarizing the cluster's dominant topic |
| **Description** | One-sentence synthesis of what users in this cluster are saying |
| **Quotes** | Verbatim excerpts from real reviews — validated to exist in the source data (no hallucinations) |
| **Action ideas** | Concrete product/engineering actions the team can take to address the theme |

### How themes are produced

```
Raw reviews
   └─ sentence-transformers embedding (all-MiniLM-L6-v2)
         └─ UMAP dimensionality reduction (5D)
               └─ HDBSCAN density clustering
                     └─ Groq / Llama-3 summarization per cluster
                           └─ Quote validator (substring match against source)
```

Clusters labelled `-1` by HDBSCAN (noise) are dropped. Each surviving cluster becomes one theme. Themes are sorted by cluster size (largest first) and capped at the token budget (`TOKEN_BUDGET_PER_RUN` in `.env`).

## Architecture

```
Phase 1 Ingestion ──► Phase 2 Clustering ──► Phase 3 Summarization
                                                       │
                                              Phase 4 Renderer
                                             /                 \
                               Phase 5 Docs MCP          Phase 6 Gmail MCP
                              (Google Doc append)        (SMTP teaser email)
                                             \                 /
                                         Phase 7 Orchestration
                                       (Groq tool-calling agent loop)
```

The MCP servers run on HuggingFace Spaces (Docs) and locally (Gmail). The orchestration agent uses Groq's tool-calling API so the LLM decides which phase to invoke next and in what order.

## Environment Variables

| Variable | Description |
|---|---|
| `GROQ_API_KEY` | Groq API key for LLM calls |
| `DEFAULT_MODEL` | Groq model ID (default: `llama-3.3-70b-versatile`) |
| `SEND_MODE` | `production` = send email · `staging` = create draft |
| `TOKEN_BUDGET_PER_RUN` | Max tokens per run (default: 500 000) |
| `GOOGLE_DOCS_ID` | Target Google Doc ID |
| `GOOGLE_DOCS_MCP_SERVER_URL` | SSE URL for deployed Docs MCP (HuggingFace) |
| `GMAIL_MCP_SERVER_URL` | SSE URL for Gmail MCP (`http://localhost:8001/sse`) |
| `RECIPIENT_EMAIL` | Email address to receive weekly teaser |
| `SENDER_EMAIL` | Gmail address used as sender |
| `GMAIL_APP_PASSWORD` | Gmail App Password (16-char, 2FA required) |

## Run Log

Every execution writes a record to `run_log.db` (SQLite):

```
run_id · product · iso_week · status · doc_id · heading_id · email_message_id · review_count · token_usage · started_at · completed_at
```

Query the log:

```bash
sqlite3 run_log.db "SELECT product, iso_week, status, review_count, token_usage FROM runs ORDER BY started_at DESC LIMIT 10;"
```
